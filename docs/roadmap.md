# Roadmap

## Fase 1 - MVP (2-4 semanas)
- Onboarding + perfil nutricional
- Generación menú semanal
- Recetas paso a paso
- Lista de compra
- Dashboard básico para demo

## Fase 2 - Producto comercial (4-8 semanas)
- Login y gestión de cuentas
- Persistencia total en PostgreSQL
- Feedback del usuario para mejorar recomendaciones
- Integración con APIs de actividad física

## Fase 3 - B2B Escalable
- Multi-tenant
- Panel admin para empresas
- Reporting de KPIs
- API pública para integraciones

## Entregable para presentación a empresas
- Demo web funcional
- Documento de propuesta de valor y ROI
- Arquitectura técnica y seguridad
- Plan de despliegue y costos aproximados
